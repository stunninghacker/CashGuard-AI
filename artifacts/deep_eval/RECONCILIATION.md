# Deep-Evaluation Integrity Reconciliation

**Date:** 2026-08-30 · **Author:** HexStrike red-team re-run
**Scope:** `artifacts/deep_eval/*.json`
**Status:** Several artifacts below were generated **before the label-leakage fix** and report the leaky `ROC-AUC ≈ 0.92` number. These are **not valid** and must not be presented as model performance.

---

## Why the old numbers were wrong

The label-leakage defect trained with features and labels built on the **same calendar day**, so rolling-window features leaked the target into the features. After the fix (day-keyed feature frames shifted forward 1 day), the honest, forecast-safe model scores **ROC-AUC 0.6273** (held-out; see `artifacts/metrics.json` and `artifacts/model.joblib`).

Any `0.92x` AUC was an artifact of that leakage and is **superseded**.
